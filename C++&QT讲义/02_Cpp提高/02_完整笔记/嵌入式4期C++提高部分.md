### 二、<span style=color:red;background:yellow;font-size:30px>类与类之间的关系（重要）</span>

#### 1、继承（泛化）

基类会成为派生类的一部分。在语义层面上：A is B。在类图的画法上：从派生类（A）指向基类（B）的实线空心三角箭头。

<img src="嵌入式4期C++提高部分.assets/image-20250805100413740.png" alt="image-20250805100413740" style="zoom:50%;" />

继承：先有基类，然后再派生出新的类，即：派生类。

泛化（一般化）：先有派生类，然后将相同的属性抽出来，然后形成了基类。

#### 2、关联

##### 双向的关联关系

彼此知道对方的存在，但是彼此并不负责对方的生命周期。在语义层面上：A has B。在代码层面上：使用的是指针或者引用。在类图的画法上：A与B之间直接使用实线连接即可。

<img src="嵌入式4期C++提高部分.assets/image-20250805101839702.png" alt="image-20250805101839702" style="zoom: 67%;" />

##### 单向的关联关系

A知道B的存在，但是B不知道A的存在，A并不负责B的销毁。在语义层面：A has B。在代码层面上：使用的是指针或者引用。在类图的画法上：使用的是从A指向B的实线箭头。

![image-20250805102459165](嵌入式4期C++提高部分.assets/image-20250805102459165.png)

#### 3、聚合

聚合关系是一种稍强一点的关联关系，<span style=color:red;background:yellow;font-size:20px>表现为整体与局部的关系，但是整体并不负责局部的销毁</span>。在语义层面上：A has B.在代码层面上：使用的是指针或者引用。在类图的画法上：从局部指向整体的空心菱形箭头。

<img src="嵌入式4期C++提高部分.assets/image-20250805104931072.png" alt="image-20250805104931072" style="zoom:50%;" />

#### 4、组合

组合关系是一种更强的关联关系，<span style=color:red;background:yellow;font-size:20px>表现为整体与局部，并且整体部分会负责局部的销毁</span>。在语义层面上：A has  B.在代码层面上：使用是子对象。在类图的画法上：从局部指向整体的实心菱形箭头。

<img src="嵌入式4期C++提高部分.assets/image-20250805105437352.png" alt="image-20250805105437352" style="zoom:50%;" />

#### 5、依赖

依赖关系是两个类之间的<span style=color:red;background:yellow;font-size:20px>一种不确定的关系</span>，语义上是：A use B的关系，这种关系是<span style=color:red;background:yellow;font-size:20px>偶然的，临时的，并非固定的</span>。在代码上表现为三种形式：

- B作为A的成员函数参数；
- B作为A的成员函数的局部变量或者B作为A的成员函数的返回值；
-  A的成员函数调用B的静态方法;

在类图的画法上：从A指向B的虚线箭头。

<img src="嵌入式4期C++提高部分.assets/image-20250805110206471.png" alt="image-20250805110206471" style="zoom:50%;" />

#### 6、总结

- 继承关系是先有基类然后有派生类，所以是垂直关系；但是其他的四种关系都是水平关系；
- 从耦合程度：依赖  < 关联 <  聚合 < 组合   <  继承；
- 从语义层面：继承：is；依赖：use；关联、聚合、组合：has；
- 从代码层面：关联、聚合、组合体现的是数据成员；依赖：体现在成员函数上；继承：即体现在数据成员，也体现在成员函数；



### 三、<span style=color:red;background:yellow;font-size:30px>面向对象的设计原则（重要）</span>

#### 0、设计要求

<span style=color:red;background:yellow;font-size:20px>**低耦合、高内聚 。**</span>

低耦合：强调的是类与类之间的关系、模块与模块之间的关系。高内聚：强调的是类内部或者模块内部的关系。

#### 1、单一职责原则

核心思想：一个类，最好只做一件事，只有一个引起它变化的原因。  

<img src="嵌入式4期C++提高部分.assets/image-20250805112617720.png" alt="image-20250805112617720" style="zoom: 50%;" />

<img src="嵌入式4期C++提高部分.assets/image-20250805112907653.png" alt="image-20250805112907653" style="zoom:50%;" />

#### 2、<span style=color:red;background:yellow;font-size:20px>开闭原则（重要）</span>

核心思想：对抽象编程，而不对具体编程，因为抽象相对稳定 。

对扩展是开放的，也就是可以无限进行扩展，但是对基类的设计是关闭的，也就不允许修改。

<img src="嵌入式4期C++提高部分.assets/image-20250805114027171.png" alt="image-20250805114027171" style="zoom:50%;" />

#### 3、<span style=color:red;background:yellow;font-size:20px>里氏替换原则（重要）</span>

核心思想：派生类必须能够替换其基类。表现形式为：

- 派生类（子类）可以实现基类（父类）的抽象方法，表现多态；（C++中的虚函数体现出来的多态）
- 但不能覆盖基类（父类）的非抽象方法；（不能使用C++中的隐藏）
- 当然派生类（子类）可以有自己的个性。 （C++中的新增成员） 

<img src="嵌入式4期C++提高部分.assets/image-20250805144318584.png" alt="image-20250805144318584" style="zoom:50%;" />

#### 4、接口分离原则

核心思想：使用多个小的专门的接口，而不要使用一个大的总接口  

<img src="嵌入式4期C++提高部分.assets/image-20250805145206676.png" alt="image-20250805145206676" style="zoom: 33%;" />

#### 5、<span style=color:red;background:yellow;font-size:20px>依赖倒置原则（重要）</span>

核心思想：面向接口编程，依赖于抽象。

<img src="嵌入式4期C++提高部分.assets/image-20250805150231298.png" alt="image-20250805150231298" style="zoom: 33%;" />

<span style=color:red;background:yellow;font-size:20px>在大多数情况下，开闭原则、里氏替换原则、依赖倒置原则会同时出现，开闭原则是目标，里氏替换原则是基础，依赖倒置原则是手段</span> 

#### 6、迪米特原则

也叫最少知识原则、或者最少知道原则。核心思想：降低耦合程度  

<img src="嵌入式4期C++提高部分.assets/image-20250805150820319.png" alt="image-20250805150820319" style="zoom:50%;" />

简言之，在复用时要尽量使用组合/聚合关系（关联关系），少用继承。

```C++
TextQuery::TextQuery(ifstream &is)
: file(new vector<string>)//为了给file进行初始化，托管堆空间
{
    string text;
    while (getline(is, text))//获取一行内容
	{       // for each line in the file
		file->push_back(text);        // 将这一行内容存放到vector尾部
		int n = file->size() - 1;     // 回去行号
		istringstream line(text);     // 将这一行的字符串内容交个line做初始化
		string word;               
		while (line >> word) {        // line以空格为分隔符，将每个单词输入到word
            word = cleanup_str(word); //将word中的所有字符都转换为小写 
            
            shared_ptr<set<size_t>> &lines = wm[word]; //将处理好之后的word插入到wm中map<string, shared_ptr<set<size_t>>>
            if (!lines) //判断智能指针是不是空的，如果是空的
                lines.reset(new set<line_no>); // allocate a new set，给智能指针托管一块堆空间
            lines->insert(n);      //将行号插入到set中
		}
	}
}
```

QueryResult AndQuery::eval(const TextQuery& text) const
{
    //lhs = Query(sought1);
    //rhs = Query(sought2);
    QueryResult left = lhs.eval(text), right = rhs.eval(text);

    shared_ptr<set<line_no> > ret_lines(new set<line_no>);  

    //取交集
    set_intersection(left.begin(), left.end(), 
                   right.begin(), right.end(),
                   inserter(*ret_lines, ret_lines->begin()));
    return QueryResult(rep(), ret_lines, left.get_file());
}

QueryResult NotQuery::eval(const TextQuery& text) const
{
    //要查询某个单词没有出现的情况，可以先查询单词出现的情况（单词、行数、每一行的内容）
    QueryResult result = query.eval(text);

    shared_ptr<set<line_no> > ret_lines(new set<line_no>);

    //这里的beg与end指向的其实是shared_ptr<set<size_t>>的begin与end
	QueryResult::line_it beg = result.begin(), end = result.end();

	vector<string>::size_type sz = result.get_file()->size();//也就是找到整篇文章的行数
    for (size_t n = 0; n != sz; ++n) {
		if (beg == end || *beg != n) 
			ret_lines->insert(n); 
		else if (beg != end) 
			++beg; 
	}
	return QueryResult(rep(), ret_lines, result.get_file());
}

### 一、C++11线程

#### 1、基本概念

- 平时写的代码就是程序，程序运行起来就是进程。
- <span style=color:red;background:yellow;font-size:20px>进程是资源拥有的基本单位，线程可以看成是轻量级进程，线程是调度或者执行的基本单位，一个进程中至少会有一个线程，main线程，也就是主线程；</span>
- 为了区分不同的进程或者线程，会给每个进程或者线程一个全局唯一的标识符，称为：进程id或者线程id。
- 进程或者线程都会有状态的概念，比如：运行、睡眠、阻塞；
- <span style=color:red;background:yellow;font-size:20px>进程或者线程启动的目的，就是为了做任务。进程或者线程做任务，其实就是指向对应的函数，可以将这种函数称为入口函数。</span>
- 线程一旦创建出来之后，它的<span style=color:red;background:yellow;font-size:20px>执行是随机的</span>，谁先执行，谁后执行，谁执行的快，谁执行的慢，这些都是随机的。
- 不同的平台上面，使用进程或者线程的接口不一样，在Windows上与Linux都有自己的函数接口，在C++11中的线程库，是跨平台的。也就是说可以在不同的操作系统上都可以使用。

```

### 三、条件变量

条件变量类是一个同步原语，它可以在同一时间阻塞一个线程或者多个线程，直到其他线程改变了共享变量（条件）并通知

template< class Predicate >

//唤醒函数（将在条件变量上睡眠的线程唤醒）

void notify_all()；//唤醒条件变量上的所有线程
```

### 二、面向对象线程池

#### 1、背景

如果有一个任务就创建一个线程去处理这个任务，然后当任务执行完毕之后，就销毁线程，如果后续还有任务到来，那么继续创建线程执行任务，当任务执行完毕之后，又销毁线程，那么如果任务量比较大，那么创建线程与销毁线程也会有很大开销，所以可以先创建一部分线程出来，然后等着接收任务，当任务执行完毕之后，线程不会立马销毁，而是继续执行其他的任务，这样就可以解决线程创建销毁带来的开销。
